## 1. 修复 Activity 主键回填错误

修改文件：

```text
events/db.py
```

修改函数：`save_user_activity`

原始位置：约第 268 行。

将函数修改为：

```python
def save_user_activity(session, record):
    activity = Activity(record)
    session.add(activity)
    session.commit()

    # dmPython returns an incorrect generated identity for this table after a
    # migration with explicit IDs. Fetch the committed row by its commit ID.
    stmt = select(Activity.id).where(
        Activity.repo_id == record['repo_id'],
        Activity.commit_id == record.get('commit_id'),
        Activity.op_type == record['op_type'],
        Activity.op_user == record['op_user'],
        Activity.path == record['path'],
    ).order_by(desc(Activity.id)).limit(1)
    activity_id = session.scalars(stmt).first()
    if activity_id is None:
        raise RuntimeError(
            f"Unable to find committed activity for repo {record['repo_id']}"
        )

    for username in record['related_users'][:USER_ACTIVITIES_GENERATE_LIMIT]:
        user_activity = UserActivity(username, activity_id, record['timestamp'])
        session.add(user_activity)
    session.commit()
```

修改目的：达梦 `dmPython` / SQLAlchemy 在已迁移历史 ID 的 `ACTIVITY` 表上返回错误的自增主键，造成 `USERACTIVITY.ACTIVITY_ID` 指向错误或不存在的活动记录。修改后在提交 `ACTIVITY` 后按本次操作的 `repo_id`、`commit_id`、`op_type`、`op_user`、`path` 查询真实 ID，再写入 `USERACTIVITY`。

## 3. 修复按天统计接口的达梦日期格式兼容问题

修改文件：

```text
statistics/db.py
```

### 3.1 新增日期转换函数

在 `convert_timezone` 函数后添加以下函数。

添加位置：约第 29 行。

```python
def date_from_database(value):
    """Normalize MySQL DATE and Dameng TO_DATE results to a datetime."""
    if isinstance(value, datetime):
        return value
    return datetime.strptime(str(value)[:10], '%Y-%m-%d')
```

### 3.2 替换日期解析代码

将文件中所有以下写法：

```python
datetime.strptime(str(row[0]), '%Y-%m-%d')
```

替换为：

```python
date_from_database(row[0])
```

本版本涉及位置：约第 75、219、266、305、345、382 行。

其中，`get_user_activity_stats_by_day` 函数中的返回行应为：

```python
ret.append((date_from_database(row[0]), row[1]))
```

其余流量统计函数中的返回行应为：

```python
ret.append((date_from_database(row[0]), row[2], int(row[1])))
```

`get_org_file_ops_stats_by_day` 函数中应为：

```python
timestamp = date_from_database(row[0])
```

修改目的：达梦 `TO_DATE()` 返回 `YYYY-MM-DD 00:00:00` 或 `datetime` 类型，而原代码只接受 `YYYY-MM-DD`，会导致管理员统计接口出现 `ValueError: unconverted data remains: 00:00:00`。

该修改覆盖以下功能：

```text
管理员活跃用户统计
管理员系统流量统计
组织文件操作统计
用户流量统计
组织流量统计
```

## 6. 修复用户活动与流量统计写入

修改文件：


### 6.1 修复用户活动统计的 REPLACE INTO 语法

修改函数：`UserActivityCounter.update_login_record`

原始位置：约第 565 行。

达梦不支持 MySQL 的 `REPLACE INTO`。删除原有构造 `REPLACE INTO UserActivityStat` 的代码，改为对每条记录先 UPDATE，若未更新任何行再 INSERT：

```python
for key in keys:
    pop_data = login_records.pop(key)
    username, timestamp, org_id = pop_data
    result = self.edb_session.execute(text('''
        UPDATE "USERACTIVITYSTAT"
        SET "USERNAME" = :username, "TIMESTAMP" = :timestamp, "ORG_ID" = :org_id
        WHERE "NAME_TIME_MD5" = :name_time_md5
    '''), {
        'name_time_md5': key,
        'username': username,
        'timestamp': timestamp,
        'org_id': org_id,
    })
    if result.rowcount == 0:
        self.edb_session.execute(text('''
            INSERT INTO "USERACTIVITYSTAT" ("NAME_TIME_MD5", "USERNAME", "TIMESTAMP", "ORG_ID")
            VALUES (:name_time_md5, :username, :timestamp, :org_id)
        '''), {
            'name_time_md5': key,
            'username': username,
            'timestamp': timestamp,
            'org_id': org_id,
        })
```

### 6.2 修复 USERTRAFFIC 写入

修改函数：`TrafficInfoCounter.update_record`

原始位置：约第 344 行。

达梦 SQLAlchemy 方言对小写双引号字段 `"user"`、`"size"` 的 ORM 写入和同名参数绑定不兼容。将 `UserTraffic` 的 ORM 新增和更新替换为以下显式 SQL，参数名使用 `traffic_user`、`traffic_size`，避免与列名冲突：

```python
if result is not None:
    size_in_db = result
    self.edb_session.execute(text('''
        UPDATE "USERTRAFFIC"
        SET "size" = :traffic_size
        WHERE "TIMESTAMP" = :timestamp
          AND "user" = :traffic_user
          AND "ORG_ID" = :org_id
          AND "OP_TYPE" = :op_type
    '''), {
        'traffic_size': size + size_in_db,
        'timestamp': date,
        'traffic_user': user,
        'org_id': org_id,
        'op_type': oper,
    })
else:
    self.edb_session.execute(text('''
        INSERT INTO "USERTRAFFIC" ("user", "ORG_ID", "TIMESTAMP", "OP_TYPE", "size")
        VALUES (:traffic_user, :org_id, :timestamp, :op_type, :traffic_size)
    '''), {
        'traffic_user': user,
        'org_id': org_id,
        'timestamp': date,
        'op_type': oper,
        'traffic_size': size,
    })
```

### 6.3 修复 SYSTRAFFIC 写入

同一函数中，将 `SysTraffic` 的 ORM 新增和更新替换为：

```python
if result is not None:
    size_in_db = result
    self.edb_session.execute(text('''
        UPDATE "SYSTRAFFIC"
        SET "size" = :traffic_size
        WHERE "TIMESTAMP" = :timestamp
          AND "ORG_ID" = :org_id
          AND "OP_TYPE" = :op_type
    '''), {
        'traffic_size': size + size_in_db,
        'timestamp': date,
        'org_id': org_id,
        'op_type': oper,
    })
else:
    self.edb_session.execute(text('''
        INSERT INTO "SYSTRAFFIC" ("ORG_ID", "TIMESTAMP", "OP_TYPE", "size")
        VALUES (:org_id, :timestamp, :op_type, :traffic_size)
    '''), {
        'org_id': org_id,
        'timestamp': date,
        'op_type': oper,
        'traffic_size': size,
    })
```

修改目的：解决统计任务中的 `REPLACE INTO` 语法错误和 `KeyError: '"size"'`，使原始流量可以写入 `USERTRAFFIC`、`SYSTRAFFIC`，随后由月度任务汇总至 `MONTHLYUSERTRAFFIC`、`MONTHLYSYSTRAFFIC`。
