# 方案

迁移规划：

1. &#x20; 客户提供新达梦数据库后，按照标准版本新部署的SQL，先创建空白表
2. &#x20; 给客户mysql备份，并且手动执行 升级SQL ，升级到 13 版本
3. &#x20; 根据脚本把升级到13 版本后的mysql数据 安表导出，只导出数据
4. &#x20; 然后用脚本把数据转换成 达梦（开启mysql兼容）识别的SQL
5. &#x20; 用脚本到转换后，有实际数据的表导入到达梦数据
6. &#x20; 用统计脚本，统计导入后数据量和mysql是否一致
